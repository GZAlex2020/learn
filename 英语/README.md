# 英语练习

小学一～三年级上基础英语互动练习（网页版）。

## 内容

按 **人教版 PEP（2024）** 课本单元组织：

| 年级 | 模块 |
|------|------|
| 一二年级 | **课本单元**（一年级上 5 单元 + 二年级上 5 单元）· 字母表 · 综合单词/听力/句型 · 数字 · 颜色 |
| 三年级上 | **课本单元**（Unit 1～6）· 综合单词/听力/句型 |

每个单元支持：单词点读、句型跟读、单词测验、听音选词、句型测验。

读音使用系统英文语音（TTS），无需额外音频文件。
