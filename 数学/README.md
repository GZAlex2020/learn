# 一二年级暑假数学复习资料

> 适用对象：一年级升二年级 · 口算慢 · 概念不清 · 应用题读不懂

本资料包含 **打印版** 和 **网页互动** 两部分，每天 15～20 分钟，暑假 8 周系统复习。

## 8 周学习计划

| 周次 | 主题 | 主要内容 |
|------|------|----------|
| 第 1 周 | 20 以内加减 | 数感、口算速度 |
| 第 2 周 | 凑十与破十 | 进位、退位 |
| 第 3 周 | 图形与比较 | 认图形、比大小 |
| 第 4 周 | 时间与人名币 | 整点、元角 |
| 第 5 周 | **应用题常用词** | 读题训练（重点） |
| 第 6 周 | 题型认读 | 看图列式、找规律 |
| 第 7 周 | 综合复习 | 口算 + 概念 + 读题 |
| 第 8 周 | 模拟小测验 | 独立完成 |
