# 应用题常用词 40 个

> **重点资料！** 很多孩子不会做应用题，是因为不认识这些词。每天认 5～7 个。

---

## 一、表示「加起来」（用加法）

| 词 | 意思 | 给孩子看 | 认读□ |
|----|------|----------|-------|
| 一共 | 总共多少 | 一共有几个 | |
| 合计 | 加起来 | 合计多少元 | |
| 总共 | 全部 | 总共 10 个 | |
| 合起来 | 加在一起 | 合起来是多少 | |
| 和 | 相加的结果 | 和是多少 | |
| 都 | 两个都要算 | 小明和小红都有 | |
| 又 | 再增加 | 又来了 3 个 | |
| 买了…又买了 | 两次购买 | 买笔又买本 | |
| 原来…现在 | 有时用加法 | 原来 5 个，又来 3 个 | |
| 增加 | 变多了 | 增加了 5 个 | |

## 五、家长怎么练

1. 指词 → 孩子读
2. 问：「一共是什么意思？」→ 孩子答：「加起来，一共多少」
3. 举例：「小明有 3 个，小红有 5 个，**一共**几个？」→ 3+5=8
