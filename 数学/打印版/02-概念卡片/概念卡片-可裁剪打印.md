# 数学概念卡片 · 可裁剪打印

> 打印后沿虚线裁剪，每天复习 5 张旧卡 + 学 3 张新卡。

---

## 卡片 1～10：符号与比较

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│      >      │  │      <      │  │      =      │
│    大于     │  │    小于     │  │    等于     │
│   5 > 3     │  │   2 < 7     │  │   4 = 4     │
└─────────────┘  └─────────────┘  └─────────────┘

┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│      +      │  │      -      │  │      ×      │
│    加法     │  │    减法     │  │    乘法     │
│   3 + 2     │  │   5 - 2     │  │   2 × 3     │
└─────────────┘  └─────────────┘  └─────────────┘

┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│      ÷      │  │     十位    │  │     个位    │
│    除法     │  │  35 的 3    │  │  35 的 5    │
│   6 ÷ 2     │  │  表示 3 个十│  │  表示 5 个一│
└─────────────┘  └─────────────┘  └─────────────┘

┌─────────────┐
│    凑十     │
│  8+5=8+2+3  │
│  =10+3=13   │
└─────────────┘
```

## 卡片 21～30：时间与人民币

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│    7:00     │  │    1 元     │  │    1 角     │
│   7 时整    │  │  = 10 角    │  │  = 10 分    │
│  分针指 12  │  │  可以换 10  │  │  1/10 元    │
│             │  │  个 1 角    │  │             │
└─────────────┘  └─────────────┘  └─────────────┘

┌─────────────┐  ┌─────────────┐
│   2 元5角   │  │   时针      │
│  = 25 角    │  │  短针，看时 │
│  = 2元+5角  │  │  分针长，看分│
```

## 使用说明

1. 每张卡片：看符号/图形 → 说名称 → 说例子
2. 会了的放「已会」盒，不会的放「再练」盒
3. 配合 [`核心概念50个.md`](核心概念50个.md) 系统学习
