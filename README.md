# 一二年级暑假复习资料

> 适用对象：一年级升二年级 · 拼音/识字/口算/读题

本资料包含 **语文** 和 **数学** 两套，结构相同，各含打印版 + 网页互动。

### 📲 安装到手机 / 平板（安卓 & iPad）

1. 双击 **`启动服务器.bat`**（或运行 `python _serve_app.py`）
2. 手机连**同一 WiFi**，用浏览器打开显示的地址（如 `http://192.168.x.x:8765/app/`）
3. **安卓**：Chrome → **安装应用** 或 **添加到主屏幕**
4. **iPad**：Safari → **分享 → 添加到主屏幕**

详见 [`app/install.html`](app/install.html)。

### 📦 安卓 APK 安装包

| 方式 | 说明 |
|------|------|
| **一键打包** | 双击 [`生成APK.bat`](生成APK.bat) → 自动含拼音/识字音频 → 输出 [`输出/暑假复习.apk`](输出/暑假复习.apk) |
| **命令行** | `python _build_apk.py`（跳过音频：`python _build_apk.py --skip-audio`） |

传到安卓手机安装即可，**无需 WiFi 和电脑服务器**，读音已内置可离线使用。

### 🌐 GitHub Pages 网页版

静态站点在 **`pages/`**（约 29MB，含音频），适合挂到 GitHub Pages：

```bash
node _build_pages.js
```

部署步骤见 [`GITHUB_PAGES.md`](GITHUB_PAGES.md)。开启后访问：

```text
https://<用户名>.github.io/<仓库名>/
```

建议：**每天语文 20 分钟 + 数学 20 分钟**（中间休息 10 分钟）。

## 整合打印（Word 练习册）

已将 **语文 + 数学全部练习题** 整合为 Word 文档，位于 [`打印版/`](打印版/)：

| 文件 | 说明 |
|------|------|
| [`一升二暑假练习册-语文（学生版）.docx`](打印版/一升二暑假练习册-语文（学生版）.docx) | 语文练习，不含答案 |
| [`一升二暑假练习册-语文（含答案）.docx`](打印版/一升二暑假练习册-语文（含答案）.docx) | 语文练习，含参考答案 |
| [`一升二暑假练习册-数学（学生版）.docx`](打印版/一升二暑假练习册-数学（学生版）.docx) | 数学练习，不含答案；**看图列式**题含示意图 |
| [`一升二暑假练习册-数学（含答案）.docx`](打印版/一升二暑假练习册-数学（含答案）.docx) | 数学练习，含参考答案 |

**包含内容：** 闯关练习（第1～8周）、题型认读、56 天每日一练。语文、数学**分开两个文档**，方便单独打印。每日一练按「第 X 天」分页。

修改 Markdown 后重新生成：

```bash
python _gen_print_doc.py
```
