## 二、24 个韵母

### 单韵母（6 个）

```
a    o    e    i    u    ü
啊   喔   呃   衣   乌   淤
```

### 复韵母（9 个）

```
ai   ei   ui       ao   ou   iu
哀   诶   威       凹   欧   优

ie   üe   er
椰   约   儿
```

> 韵母例字 **统一用第一声**（儿 ér 为特殊韵母，仍读「儿」）

### 鼻韵母（9 个）

```
an   en   in   un   ün
安   恩   因   温   晕

ang  eng  ing  ong
肮   亨   英   翁
```

### 韵母口诀

```
a o e i u ü，六个单韵母，
ai ei ui，ao ou iu，
ie üe er，九个复韵母，
an en in un ün，ang eng ing ong，
九个鼻韵母，一共二十四。
```

## 三、四声（声调）

| 声调 | 名称 | 符号 | 举例 | 读法 |
|------|------|------|------|------|
| 第一声 | 阴平 | ˉ | mā 妈 | 声音 flat，高高平 |
| 第二声 | 阳平 | ˊ | má 麻 | 声音上扬 ↗ |
| 第三声 | 上声 | ˇ | mǎ 马 | 声音先降再升 ↘↗ |
| 第四声 | 去声 | ˋ | mà 骂 | 声音下降 ↘ |

### 四声儿歌

```
一声平，二声扬，
三声拐弯四声降。
```

### 标调规则（简单版）

1. **有 a 标 a**：jiā（家）、xiǎo（小）
2. **没 a 找 o e**：hǎo（好）、hē（喝）
3. **i u 并列标后面**：liú（流）、duì（对）
4. **j q x 和 y， ü 上两点要省略**：jū（居）、qù（去）

## 四、整体认读音节（16 个）

> 这些音节 **不用拼**，直接整体认读。

```
zhi  chi  shi  ri
zi   ci   si
yi   wu   yu
ye   yue  yuan
yin  yun  ying
```

### 记忆口诀

```
 zh ch sh r z c s，
 yi wu yu ye yue yuan，
 yin yun ying，
 整体认读十六个。
```
