# 拼读规则速记

> 第 2 周重点学习，配合声母韵母表一起使用。

---

## 一、两拼音节（声母 + 韵母）

**拼读方法：** 声母短，韵母长，快速连读。

| 例字 | 拼音 | 拼读过程 | 说明 |
|------|------|----------|------|
| 爸 | bà | b—à→bà | 声母 b + 韵母 à |
| 妈 | mā | m—ā→mā | 声母 m + 韵母 ā |
| 大 | dà | d—à→dà | 声母 d + 韵母 à |
| 地 | dì | d—ì→dì | 声母 d + 韵母 ì |
| 他 | tā | t—ā→tā | 声母 t + 韵母 ā |
| 你 | nǐ | n—ǐ→nǐ | 声母 n + 韵母 ǐ |
| 好 | hǎo | h—ǎo→hǎo | 声母 h + 韵母 ǎo |
| 花 | huā | h—u—ā→huā | 三拼音节（见下） |

**练习：** 家长说「b—à」，孩子合读「bà」。

---

## 二、三拼音节（声母 + 介音 + 韵母）

**介音：** i、u、ü 放在声母和韵母中间。

| 例字 | 拼音 | 拼读过程 |
|------|------|----------|
| 小 | xiǎo | x—i—ǎo→xiǎo |
| 快 | kuài | k—u—ài→kuài |
| 月 | yuè | y—u—è→yuè |
| 鸟 | niǎo | n—i—ǎo→niǎo |
| 六 | liù | l—i—ù→liù |
| 说 | shuō | sh—u—ō→shuō |

**口诀：** 声母轻，介音快，韵母响，连起来。

---

## 三、ü 的特殊规则

### 规则 1：j q x 和 y 后面，ü 写成 u

| 汉字 | 正确写法 | 错误写法 |
|------|----------|----------|
| 居 | jū | jǖ（ü 上两点不能省） |
| 去 | qù | qǜ（ü 上两点不能省） |
| 西 | xī | （无 ü） |
| 鱼 | yú | yǖ（ü 上两点不能省） |

**口诀：** j q x 小淘气，见到 ü 把点去。

### 规则 2：n l 和 ü 相拼，ü 保留两点

| 汉字 | 拼音 |
|------|------|
| 女 | nǚ |
| 绿 | lǜ |

## 四、标调规则（详细版）

### 优先级顺序

```
1. 有 a 标 a     →  huā（花）  xiǎo（小）
2. 没 a 找 o e   →  hǎo（好）  hē（喝）
3. i u 并列标后面 →  liú（流）  duì（对）
4. 单个韵母标上面 →  mā（妈）  nǐ（你）
```

### 练习：给下面音节标调

| 音节 | 标调后 | 汉字 |
|------|--------|------|
| ma（第一声） | mā | 妈 |
| ma（第三声） | mǎ | 马 |
| hao（第三声） | hǎo | 好 |
| shui（第三声） | shuǐ | 水 |
| liu（第二声） | liú | 流 |

## 五、整体认读音节（不拼读，直接读）

| 音节 | 汉字 | 音节 | 汉字 |
|------|------|------|------|
| zhi | 知 | yi | 一 |
| chi | 吃 | wu | 五 |
| shi | 十 | yu | 鱼 |
| ri | 日 | ye | 叶 |
| zi | 字 | yue | 月 |
| ci | 词 | yuan | 元 |
| si | 四 | yin | 音 |
| | | yun | 云 |
| | | ying | 英 |

**注意：** 整体认读音节 **不能拆开拼**，看到 zhi 直接读「知」，不要读成「zh—i」。

## 六、易混淆拼音对比

| 对比组 | 区别 | 例字 |
|--------|------|------|
| b / p | b 不送气，p 送气 | bà爸 / pà怕 |
| d / t | d 不送气，t 送气 | dà大 / tà踏 |
| n / l | n 鼻音，l 边音 | nǐ你 / lǐ里 |
| z / zh | z 平舌，zh 翘舌 | zì字 / zhī知 |
| c / ch | c 平舌，ch 翘舌 | cì次 / chī吃 |
| s / sh | s 平舌，sh 翘舌 | sì四 / shí十 |
| an / ang | 前鼻音 / 后鼻音 | bān班 / bāng帮 |
| en / eng | 前鼻音 / 后鼻音 | bēn奔 / bēng崩 |
| in / ing | 前鼻音 / 后鼻音 | jīn今 / jīng京 |
