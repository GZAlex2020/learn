# 一二年级暑假语文复习资料

> 适用对象：一年级升二年级 · 拼音薄弱 · 识字较少 · 考试时读不懂题目

本资料包含 **打印版** 和 **网页互动** 两部分，每天 15～20 分钟，暑假 8 周系统复习。

---

## 快速开始

### 第一步：家长先看

打开 [`打印版/00-家长使用说明.md`](打印版/00-家长使用说明.md)。

### 第二步：打印必备材料

| 文件 | 用途 |
|------|------|
| [声母韵母声调表](打印版/01-拼音巩固/声母韵母声调表.md) | 贴墙上，每天读一遍 |
| [**互动拼音表**](网页互动/拼音表.html) | **电脑点读** 🔊 |
| [考试题目常用词50个](打印版/03-读题训练/考试题目常用词50个.md) | **重点！** 解决读不懂题 |
| [识字卡片-可裁剪打印](打印版/02-识字卡片/识字卡片-可裁剪打印.md) | 裁剪成卡片 |
| [暑假学习打卡表](打印版/05-打卡表/暑假学习打卡表.md) | 每天打卡 |

### 第三步：每天做一页

[`打印版/04-每日一练/暑假56天每日一练.md`](打印版/04-每日一练/暑假56天每日一练.md)

### 第四步：网页互动

双击 [`网页互动/index.html`](网页互动/index.html)

| 模块 | 功能 |
|------|------|
| 互动拼音表 | 完整拼音表点读 |
| 拼音练习 | 看字选拼音 / 听音选字 |
| 声母韵母 | 点读学习 |
| 识字配对 / 卡片 | 字音复习 |
| 读题训练 | 听懂题目要求 |
| 题目常用词 | 考试关键词 |

## 8 周学习计划

| 周次 | 主题 | 对应资料 |
|------|------|----------|
| 1 | 声母韵母 | 拼音表 + 闯关第 1 周 |
| 2 | 拼读与声调 | 拼读规则 + 闯关第 2 周 |
| 3 | 生活常用字 | 识字卡片 1～3 组 |
| 4 | 课本高频字 | 识字卡片 4～5 组 |
| 5 | **题目常用词** | 读题训练（重点） |
| 6 | 题型认读 | 题型认读 + 读题闯关 |
| 7 | 综合复习 | 每日一练 + 网页互动 |
| 8 | 模拟小测验 | 读题闯关 + 打卡总结 |
