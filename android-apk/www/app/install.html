📲 安装到手机 / 平板

无需应用商店，添加到桌面后全屏使用，支持离线练习。

🤖 安卓 🍎 iPad / iPhone 📦 安装包 APK
注意：不能直接双击 html 文件。需先在电脑上启动服务器，手机连同一 WiFi 用浏览器访问。

🤖 安卓手机 / 平板（推荐 Chrome）

第一步：电脑启动服务
  1. 电脑与安卓设备连同一 WiFi
  2. 双击 启动服务器.bat（或运行 python _serve_app.py）
  3. 记下显示的地址，如 http://192.168.1.100:8765/app/
第二步：安卓安装
  1. 用安卓上的 Chrome 浏览器 打开上述地址（不要用微信内置浏览器）
  2. 进入首页后，任选一种方式安装：
    • 点首页绿色按钮 「安装应用到桌面」（若出现）
    • 或 Chrome 右上角 ⋮ → 添加到主屏幕
    • 或 Chrome 菜单 → 安装应用 / 安装 Summer Review
  3. 确认后，桌面会出现 「暑假复习」 图标
第三步：使用
  • 从桌面图标打开，全屏运行，无浏览器地址栏
  • 首次在线玩一遍后，读音会缓存，之后可断网练习
  • 电脑服务器可关闭，已安装的应用仍可离线使用

🍎 iPad / iPhone（Safari）

  1. 同样先启动电脑上的服务器，记下地址
  2. 用 Safari 打开 http://192.168.x.x:8765/app/
  3. 点底部分享 □↑ → 添加到主屏幕
  4. 名称保持「暑假复习」，点添加

📦 安装 .apk 安装包

方式一：一键自动打包（推荐）
  1. 双击 生成APK.bat（或运行 python _build_apk.py）
  2. 脚本会自动：生成图标 → 下载拼音/识字 MP3 → 编译 APK
  3. 完成后在 输出/暑假复习.apk 找到安装包
  4. 传到安卓手机安装（需允许「未知来源」），完全离线可用

首次约 5～15 分钟（需联网）；之后约 1～3 分钟。若只要小包可运行 python _build_apk.py --skip-audio。

方式二：在线 PWA 转 APK（需公网 HTTPS 地址）

  1. 先把本资料部署到公网 HTTPS 地址（如 GitHub Pages）
  2. 打开 PWABuilder.com
  3. 输入 https://…/app/ 地址，生成并下载 Android APK

若已用方式一安装 APK，效果与 Chrome「安装应用」相同，且更方便传给孩子设备。

常见问题

  • 微信里打不开？ 点右上角「…」→ 用浏览器打开 → 选 Chrome
  • 没有「安装应用」按钮？ 用 Chrome；或菜单 → 添加到主屏幕
  • 听不到声音？ 先在线把语文模块玩一遍，缓存 MP3 后再断网
  • 换 WiFi 后打不开？ 已安装的应用离线仍可用；重新安装需新地址
